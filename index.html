动态壁纸

一条流水线走完：立绘 → 万相待机循环原片 → 色彩锁定 / 补帧 60FPS / 4K 超分得到母版 → 四端裁剪 + 调色 → 逐端导出并自动下载。顺序是「先重处理、后剪辑」：补帧与超分都要吃干净、帧间隔均匀的画面，先裁剪再超分则等于把压缩瑕疵一起放大（先超分再裁剪是超采样降采样，清晰得多）。

① 上传立绘 / 视频 待上传

多张立绘会各跑一遍「万相待机循环 → 色彩锁定 → 补帧 60FPS → 4K 超分」，跑完自动下载；任务提交后本页立即刷新，进度去【任务队列】看。视频直接当母版，跳过全部重处理。

视频模型
循环时长

要的是「一张会呼吸的静态插画」：脚几乎不动，力从脚底一路传到发梢，越到末端越柔越晚，整段只走完一个循环。时长已固定 6 秒（不再提供 4/8 秒：同样的位移被压缩后速度变快，就会从「柔」变成「抽搐」），保证每次的呼吸节奏与眨眼时机完全一致。嘴部全程锁死、与参考立绘一致，不做任何表情变化；整段只在三分之二处（约 4 秒）眨眼一次。一次只生成一版，6 秒视频按次计费。

② 重处理母版 等待原片

原片出来后自动按「色彩锁定 → 补帧 60FPS → 4K 超分」走完，得到的 4K/60 母版才是剪辑与导出的底片。这一步只做一次，四端导出都从同一份母版裁剪，不必超分四次。

③ 四端剪辑 等待母版

母版会自动成为下方画布的源。每个预览框可独立拖动调整裁剪焦点；需要四端一起动时点开「连接关系」，拖动主画布即可联动。调色只影响导出效果，不动母版本身。导出在浏览器里只做「裁剪 + 调色预览」，成片由本机后端 ffmpeg 用同一套调色公式（3D LUT + 空间滤镜）确定性渲染。

任务队列
